 📌 Project Overview

SOCFusion is a web-based Multi-Source Threat Correlation Engine designed to help security teams analyze and correlate security alerts from different sources.

The platform groups related security events into unified incidents, maps detected activities to MITRE ATT&CK techniques, calculates risk scores, and provides an interactive dashboard for security investigation.

🎯 Objectives

- Centralize security alerts from multiple sources
- Correlate related security events
- Reduce duplicate and isolated alerts
- Generate unified security incidents
- Map attacks to MITRE ATT&CK techniques
- Calculate incident risk scores
- Provide an analyst-friendly investigation dashboard

🚀 Key Features

- Multi-source security alert processing
- Event correlation
- Incident grouping
- MITRE ATT&CK mapping
- Risk scoring
- Alert severity analysis
- Incident timeline
- Interactive SOC dashboard
